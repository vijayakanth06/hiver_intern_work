🏛️ System Architecture & Engineering Specifications

1

PII Sanitizer

Redacts emails, phone numbers, order IDs (`[ORDER_ID]`) and validates English text.

2

Hybrid Vector Search

Combines dense BGE-M3 FAISS index (112k passages) with sparse BM25Okapi via Reciprocal Rank Fusion.

3

Cross-Encoder Re-Ranker

Deep token interaction scoring with `cross-encoder/ms-marco-MiniLM-L-6-v2` + MMR diversity.

4

Fine-Tuned DeBERTa-v3

Sequence classification with class-weighted Focal Loss ($\gamma=2.0$) & temperature calibration ($T=1.36$).

5

Conformal Risk Escalation

Guarantees $\ge 95\%$ safety recall on high-risk inquiries via asymmetric cost threshold optimization.
